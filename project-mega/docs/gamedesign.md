# 第一个练习游戏：10 分钟完整作品

## 体验目标

- 这不是大项目中的前 10 分钟切片，而是一个可独立成立的 10 分钟完整练习游戏。
- 类型定位为：线性第一人称氛围探索 / 轻交互 / 轻谜题 / walking sim。
- 目标是练习完整闭环：开场、核心机制、一次升级、一个小高潮、明确结尾。
- 核心体验不是解释世界观，而是让玩家经历一次“感知恢复”的过程。

---

## 设计边界

适合：

- 一个地点
- 一条主路径
- 一个核心动作
- 两到三个阶段变化
- 一个明确结尾

不适合：

- 开放探索
- 多机制并行
- 复杂谜题链
- 大量设定文本
- 分支结局

---

## 10 分钟流程（4 区 + 1 结尾）

### 1) 苏醒间（0:00–1:30）

功能：开场、建立身体存在感、教学第一个交互。

- 空间建议：主房间约 6m × 8m，附带 2m × 5m 小出口走廊，高 2.6m–3m。
- 氛围：封闭、近景、压抑，画面略模糊，音频闷塞。
- 内容：玩家醒来，只看到墙体、设备、接口、近距离细节。
- 交互：一次明确触发（触碰校准触点 / 拔出接口 / 激活光源核心）。
- 结果：视野稍微稳定、噪声变化、出口开启。

### 2) 校准走廊（1:30–3:30）

功能：引入核心机制“感知恢复”。

- 空间建议：主走廊长 18m–24m，宽 2.5m–3m，可带一个 2m × 2m 的侧壁观察凹槽。
- 氛围：长直或轻折线，方向明确，前段标识模糊，后段逐渐可读。
- 内容：玩家接触第一个正式校准节点，理解环境会随恢复而变清晰。
- 反馈：视觉失真减弱、白噪下降、路径可辨识度提高。
- 原则：不要做成“找三个开关”，这里只做一次强反馈原型演示。

### 3) 主校准室（3:30–6:30）

功能：作为中段主空间，给出一次最完整的小型交互闭环。

- 空间建议：主厅约 16m × 20m，高 8m–12m。
- 氛围：空、安静、巨大，第一次让玩家感到设施尺度。
- 内容：中央装置失效，玩家需要先去侧面控制台，再回到中央触发主设备。
- 结构：两步式交互，不做复杂谜题。
- 结果：设施部分恢复，上行路径开启。

### 4) 垂直转换井（6:30–8:30）

功能：建立巨构垂直感，作为高潮前过渡。

- 空间建议：井道直径 8m–12m，可见高度 30m 以上，实际移动高度 10m–18m。
- 形式建议：优先使用缓慢上升平台或电梯，不做复杂平台跳跃。
- 氛围：低频机械声、深井回响、局部缝隙透出外部巨大弧面或维护结构阴影。
- 内容：这里不需要谜题，重点是观察、等待、感受上升。

### 5) 观测端点（8:30–10:00）

功能：给出最终奖励、尺度揭示和轻微身份暗示。

- 空间建议：观测平台约 8m × 12m，或狭长观景端廊 4m × 10m。
- 内容：玩家看到 Shellworld 巨构的一角，而不是全景说明。
- 推荐视觉：壳层内壁弯向天穹、巨型维护梁、远处灯带、失效光阵、冷却结构阴影。
- 结尾触发：终端或系统短暂显示异常记录，暗示玩家不是第一次被唤醒，可能是被反复重建的观察者实例。
- 结束方式：淡出或黑屏，不解释全部真相。

---

## 核心交互机制

- 唯一核心机制：恢复感知。
- 建议形式：靠近节点、重连接口、接触校准场、完成一次简短对准操作。
- 不要 UI 化成显式能力树或任务列表。
- 玩家体验到的应该是“重新抓住现实”，而不是“解锁能力”。

### 推荐反馈

- 视觉更清晰
- 白噪减少
- 环境声层次增加
- 空间边界和指示变得可读
- 材质或轮廓从噪点状态恢复

---

## 节奏原则

- 路径必须清晰，前 10 分钟不能让玩家迷路。
- 每个区域只承担一个主要功能，不要在单一区域里混入太多叙事任务。
- 玩家实际有效游玩面积建议控制在 250㎡–500㎡。
- 区域数量控制在 5 个以内，重点是体验编排，不是大地图生产。

---

## 叙事控制原则

- 不解释大设定，不讲完整历史。
- 文本极少（建议不超过 3 句）。
- 不出现大量专有名词。
- 重点是：让玩家感觉到异常、秩序、衰退和循环暗示。
- 结尾只给“轻微反转”，不要做完整设定揭露。

---

## 白盒关卡搭建清单

白盒阶段只验证以下目标：

- 路径是否清晰
- 空间比例是否舒适
- 区域切换是否有效
- 交互点是否足够明确
- 全流程是否能稳定落在 10 分钟左右

白盒阶段暂不处理：

- 精细美术
- 高级材质
- 复杂特效
- 大量文本
- 复杂 UI

### 总流程

```text
苏醒间
→ 校准走廊
→ 主校准室
→ 垂直转换井
→ 观测端点
→ 结束
```

玩家全程只需要理解一件事：

> 往前走，完成当前唯一明确交互，到达更高处的观测点。

### 推荐搭建顺序

1. 先搭整条主路线骨架
2. 再确定每区入口 / 出口视线
3. 再放交互点
4. 最后做门控和节奏验证

### 关卡骨架

先用最简单体块搭完整路径，只包含：

- 地板
- 墙体
- 天花
- 门洞
- 平台
- 电梯 / 升降平台占位
- 观景窗开口

要求：

- 玩家从起点到终点必须无歧义可通
- 不放支路
- 不放无意义房间
- 不放收藏品和装饰性目标

验收标准：

- 从头走到尾不迷路
- 裸跑全流程约 2–4 分钟
- 区域切换有明显差异感

### 区域 1：苏醒间

目标：建立开场、教学第一次交互、把玩家送出去。

搭建项：

- 一个主房间，约 6m × 8m
- 天花高度 2.6m–3m
- 一个玩家出生点
- 一面主要注意力墙
- 一个唯一明显出口
- 出口初始关闭
- 一个靠近即可注意到的交互点

交互项：

- 玩家靠近交互物
- 按键触发
- 播放一次明确反馈
- 出口开启

检查项：

- 出生后 3 秒内能看到交互目标
- 完成交互后 2 秒内能看到出口变化
- 不需要转圈找路

### 区域 2：校准走廊

目标：引入“感知恢复”核心机制。

搭建项：

- 一条主走廊，长度 18m–24m
- 宽度 2.5m–3m
- 一次轻微折线
- 一个小观察凹槽或侧壁缺口
- 走廊尽头一扇门或开口

交互项：

- 一个校准节点
- 触发前前方出口识别度较弱
- 触发后出口变明确 / 灯亮 / 指引显现

检查项：

- 进入后 5–10 秒内发现节点
- 节点激活后立刻理解前路被开启或变清晰
- 不需要找第二个机关

### 区域 3：主校准室

目标：作为中段主空间，完成本作唯一一段稍完整的交互闭环。

搭建项：

- 一个大空间，约 16m × 20m
- 高度 8m–12m
- 中央主装置占位
- 一侧控制台平台
- 从入口能一眼看到中央装置
- 能隐约看到上方出口，但初始不可达

交互流程：

```text
进入主厅
→ 看到中央装置无响应
→ 去侧面控制台
→ 回中央主装置交互
→ 上行路径开启
```

交互项：

- 侧面控制台 1 个
- 中央主装置 1 个
- 上行门 / 平台初始关闭
- 中央装置激活后，上行路径开启

限制：

- 不放多个控制台
- 不做密码谜题
- 不做环形迷宫
- 不让玩家找不到先后顺序

### 区域 4：垂直转换井

目标：制造“向上”“接近终点”的高潮前感觉。

搭建项：

- 一个竖向空间，直径 8m–12m
- 可见高度尽量大，建议 30m 以上
- 实际上升高度 10m–18m
- 一个上升平台 / 电梯占位
- 顶部出口开口
- 若干远处结构占位块

机制项：

- 玩家进入平台区域
- 触发上升
- 上升过程中锁定主要视线到外部或上方
- 到顶后自动开门或开放出口

节奏要求：

- 上升时间控制在 20–40 秒
- 不能太短，也不能过长

### 区域 5：观测端点

目标：完成奖励、尺度揭示和结尾。

搭建项：

- 一个小型观测平台，约 8m × 12m，或狭长观景廊道 4m × 10m
- 一面大开口 / 观景窗
- 一个终端或记录装置
- 一个结尾触发区

空间要求：

- 玩家一进入就会被视线拉向外部
- 外部必须有大体块占位，不能只是空天空盒
- 终端位于视野第二焦点，而不是第一焦点

结尾流程：

```text
玩家走到观景点
→ 停留观察
→ 靠近终端
→ 弹出一句异常记录
→ 黑屏结束
```

白盒阶段外部至少放置：

- 一段巨大弧面
- 一条横向巨梁
- 一组远处光点或结构块

### 全局门控

每区只保留一个当前目标：

- 苏醒间：激活交互点
- 校准走廊：激活校准节点
- 主校准室：控制台 → 中央装置
- 垂直转换井：进入平台并上升
- 观测端点：走向观景点并查看终端

门控方式优先使用：

- 门开启
- 灯亮
- 平台升降
- 障碍移开
- 声音提示

### 玩家引导

统一白盒规则：

- 当前交互点比环境更亮
- 当前可走出口比其他表面更亮
- 已失效目标保持暗
- 尽量不用文字提示，优先测试纯空间引导

### 白盒测试

第一次测试：纯路径测试

- 记录玩家在哪个区域停顿最久
- 记录哪里会回头
- 记录哪里第一眼看不到目标
- 若停顿超过 10 秒仍不知去哪，就必须调整

第二次测试：节奏测试

目标时长：

- 苏醒间：1–1.5 分钟
- 校准走廊：1.5–2 分钟
- 主校准室：2.5–3 分钟
- 垂直转换井：1.5–2 分钟
- 观测端点：1 分钟

第三次测试：视线测试

- 玩家进入区域后的第一眼看到什么
- 第二眼看什么
- 是否自然落到交互目标
- 是否能看见下一步去向

### 白盒资产最小集

- 墙体块
- 地板块
- 天花块
- 门框块
- 平台块
- 大型结构占位块
- 交互点占位
- 控制台占位
- 电梯平台占位
- 观景窗开口模块

材质只用 3–4 种颜色区分：

- 中性灰：普通结构
- 深灰：不可走区域
- 浅亮色：当前可互动
- 强亮色：当前主要目标

### 最小可玩版本（MVP）

- 五个区域全部连通
- 三次关键交互可触发
- 一次两步式主厅交互成立
- 竖井可上升
- 终点可触发结尾
- 全流程可在 8–12 分钟完成

### 实际制作顺序

第一轮：

- 只搭所有空间轮廓
- 不做特效
- 不做剧情文本

第二轮：

- 加全部门控
- 加交互触发
- 跑通全流程

第三轮：

- 调空间比例
- 调步行时间
- 调视线引导

第四轮：

- 再考虑氛围灯光
- 再考虑音效
- 最后补少量叙事信息

```text
│  │                  [终端] │  │
│  └────────────────────────┘  │
│                              │
└──────────────────────────────┘
```

推荐原因：

- 入口较窄，向前几步后视野展开，构图更容易控制
- 更容易让玩家先看外景，再看终端
- 更适合做简洁有力的结尾

### 推荐整体连接摆放

适合白盒阶段的平面排布：

```text
[苏醒间] -- [校准走廊] -- [主校准室]
                             |
                             |
                           [转换井]
                             |
                             |
                           [观测端点]
```

优点：

- 好摆放
- 好检查全局流线
- 不容易混乱
- 空间体量可以自然逐步增大

### 关键视线节点

- 苏醒间：出生点 → 交互点 → 门开启
- 校准走廊：入口 → 校准节点 → 亮起的前路
- 主校准室：入口 → 中央装置 → 侧面控制台 → 回中央 → 上行出口
- 垂直转换井：进入平台 → 上看 / 外看 → 顶部出口
- 观测端点：入口 → 外景 → 终端 → 黑屏结束

### 最简可搭版本

如果需要先快速验证流程，可先做最简版本：

- 一个矩形苏醒房
- 一条长走廊
- 一个矩形大房间，带左侧控制台和中央装置
- 一个圆形或方形竖井，带升降平台
- 一个狭长观景平台，带终端
