# 世界观

## 1.世界概述
Shellworld 所处文明在 2026 年之后进入持续加速期：强 AI、自动化工业、轨道资源开发与认知工程彼此耦合，最终推动人类文明迈入准二级阶段。巨构能够高度调度恒星能量、重塑环境与感知，但文明并非毁于单纯的物理匮乏，而是毁于认知层面的污染与失真。

## 2.时间线
- 2026—2080：加速起点
  强 AI 深度进入科研、制造、调度与治理系统，全球生产效率剧烈提升；自动化与认知技术的结合开始改变社会结构。

- 2080—2160：高自治工业阶段
  机器人体系、材料工程、能源网络与合成制造走向高度协同，地表工业逐步转向由算法和自治系统主导。

- 2160—2280：轨道工业扩张
  近地轨道、月球与小行星资源开发规模化，文明开始具备脱离单一行星表面的长期建设能力。

- 2280—2420：恒星系级工程准备期
  巨型能源采集阵列、空间制造生态与长时运行维护系统逐渐成熟，为更高等级文明工程奠定基础。

- 2450：进入准二级文明阶段
  文明已能够在恒星系尺度上高效获取、调度并储存能量，社会进入真正意义上的后稀缺边缘。

- 2485：Shellworld 立项
  壳世界被定义为文明巅峰工程，不只是生存设施，更是对居住、感知、秩序与意识形态的总体重构。

- 2515—2650：Shellworld 建设期
  巨构主体持续扩张并最终完成，内部生态、人工气候、维护系统、分层空间与感知渲染基础设施逐步投入运行。

- 2655—2745：文明高峰
  感知渲染全面成熟，意识挂载高度普及，物质匮乏基本被解决。社会表面稳定而繁荣，但阶级分化与感知质量差异日益明显。

- 2725—2760：异常累积期
  语义饱和、感知疲劳、认知污染与现实解释系统错位开始出现，最初被视作局部故障或心理适应问题。

- 2748：意识污染事件
  原本用于维持感知一致性与意识连续性的系统发生灾难性反噬，污染从个体认知层面扩散到社会结构与基础设施控制层。

- 2748—2815：系统性衰败
  自动化系统持续运行但目标逐渐偏离，秩序没有瞬间崩塌，而是在静默维护、错误重复与认知失真中缓慢腐坏。

- 2820 之后：玩家所处时代
  玩家醒来时，Shellworld 已经度过最辉煌的时代，只剩仍在运转的残余系统、被磨损的感知秩序，以及难以确认真假的历史痕迹。
